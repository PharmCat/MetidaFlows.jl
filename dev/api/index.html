Documentation for MetidaFlows.

The reference is split by subject. Everything exported by the package is in Graph and nodes and the two pages after it; the rest is public but not exported.

  • Types — the workflow, the node, ports, specifications, state, the container supertypes
  • Graph and nodes — building a graph, invalidation, readiness, containers, the node register
  • Reading and writing a node — getters and setters
  • Execution — execute!, both schedulers, stopping a run
  • Port metadata — getmeta, getinputmeta and their hooks
  • Serialization and schemas — snapshots, the value codec, settings schemas
